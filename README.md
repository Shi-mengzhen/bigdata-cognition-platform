# 大数据认知平台 · Big Data Cognition

面向大数据技术专业的知识认知与学以致用平台。围绕「认知 → 技术 → 流程 → 实践 → 应用」主线，
将三年专业课程系统化为可访问、可运行、可视化的知识站点，是作者的毕业设计作品。

## 功能特性

- **8 个页面模块**：首页 / 认知基础 / 技术栈与架构 / 数据处理全流程 / 实践案例 / 动手实验室 / 行业应用 / 关于
- **动手实验室（lab.html）**：三个浏览器里直接玩的交互实验，全部原生 JS、零依赖——
  - **MapReduce 词频统计器**：粘贴文本，分 Map → Shuffle → Reduce 三阶段动画展示词频统计，支持单字 / 二元两种切分粒度，直观呈现中文分词的难点
  - **数据清洗台**：12 条预置脏数据（重复、缺失、异常、格式混乱），四条清洗规则可开关，实时观察「12 条 → 7 条」的清洗过程
  - **数据量级感受器**：GB–ZB 拖杆换算成电影 / 照片 / 下载时长，内置 IDC 预测的 2025 全球数据量等锚点
- **数据可查证**：首页及各页图表均标注确切来源（IDC《Data Age 2025》、CNNIC 第 49/51/53/55 次报告），无凭空捏造的示意数据
- **可视化表达**：内置轻量级图表引擎（条形图、环形图、数字滚动），6 幅手绘内联 SVG 示意图
  （5V 特征、课程映射、六环节流水线、MapReduce 流程、行业-技术-价值映射、学习主线）
- **学以致用**：实践案例页含可运行的 Python 数据清洗、SQL 分析、MapReduce 词频统计示例
- **专业特色**：内容与专业课程体系一一对应，附「三年学习路径」时间线与课程映射表

## 动手实验室：交互逻辑与教学点

三个实验的脚本内嵌在 `lab.html` 页面内（`main.js` 只保留全站通用逻辑），全部原生 JS、零依赖。
页面加载时 `DOMContentLoaded` 会自动把三个实验各跑一遍，保证首屏就有可看的运行结果。

### Lab 01 · MapReduce 词频统计器

**交互流程**

1. 输入区预置朱自清《匆匆》公版节选，可粘贴任意文本；可选「单字 / 二字组合」两种切分粒度，可开关「过滤虚词」
2. 点击「运行统计」后三个阶段框依次点亮（`setTimeout` 分阶段，500ms / 1050ms），模拟分布式计算的时序感：
   - **Map**：把文本切成 `(token, 1)` 键值对，展示前 12 个并给出总数
   - **Shuffle**：相同 key 归为一组，展示「词 ← 收到 N 个 1」
   - **Reduce**：组内求和 → 按频次排序 → Top 10 迷你条形图（宽度按最大值归一化，40ms 逐条生长动画）
3. 「恢复默认文本」一键还原；页脚实时输出统计口径（token 总数 / 不同词数 / Top10 覆盖率）

**核心实现**：正则 `/[a-zA-Z0-9]+|[\u4e00-\u9fa5]/` 切 token，英文整体转小写、中文按单字；「二字组合」模式将相邻汉字两两合并为 bigram（英文单词保持整体）；虚词表用 `Set` 过滤，且过滤发生在 bigram 合并**之后**。

伪代码（与 `lab.html` 中的 `tokenize` + `runWC` 一一对应）：

```text
输入：text 文本、gram 切分粒度（1=单字 / 2=二字组合）、useStop 虚词开关

tokens ← 正则切分 text                      # 匹配英文单词或单个汉字，英文转小写
if gram = 2: 相邻汉字 token 两两合并为 bigram    # 英文单词保持整体
if useStop: tokens ← 去除虚词表中的 token    # 过滤在合并之后 → 留下「子去」类组合
pairs  ← [(t, 1) for t in tokens]           # Map：每个 token 发一个键值对
groups ← 按 key 归并 pairs，值为若干个 1     # Shuffle：相同 key 归到一组
top10  ← 按 count 降序取前 10                # Reduce：组内求和 → 排序 → 截断
条形宽度 ← count / max(count)，Top10 逐条 40ms 生长动画
```

**教学点**

- **中文分词是难题**：切到「二字组合」会冒出「子去」这类无意义组合——中文没有空格，真实工程要用 jieba 这类分词器。这个麻烦是故意让学生亲手撞上的，而不是课本上一句带过
- **统计结果会讲故事**：「日子」「痕迹」刻意不进虚词表——它们是《匆匆》的题眼，应该留在 Top 榜上
- **价值密度低**：页脚口径显示少数高频虚词占了大部分出现次数，有信息量的长尾只占小头——5V 特征里最难讲的一条，用数据本身演示

### Lab 02 · 数据清洗台

**交互流程**

1. 预置 12 条「乡村电商订单」脏数据，混入真实项目最常见的四类毛病：重复订单、金额缺失、异常值（99999 疑似小数点错位、-30 负数）、格式混乱（省份简称、`2024/1/5`、`2024-13-01` 非法日期）
2. 四条规则复选框任意开关，表格即时重渲染；被剔除行加删除线，被修正单元格高亮并打标签（`已补全` / `中位数填充` / `已规范`），右列始终保留原始问题标注
3. 顶部统计行实时变化：`原始 12 条 → 当前 N 条 · 去重 x · 剔除 y · 填充 z · 格式修正 w 行`

**核心实现**：纯函数式 `renderClean()`，规则按固定顺序应用——**格式统一（先修正，供后续判断）→ 剔除异常（负金额 / ≥10000 / 非法日期）→ 按订单号去重 → 缺失金额用有效值中位数 128.5 填充**。规则间存在依赖：填充用的中位数取自「剔除异常之后」的有效金额，所以先修格式、再剔异常，最后才算填充——关闭前面的规则，能观察到下游结果的连锁变化。

**教学点**

- **清洗不是「删到只剩干净的」**：去重保真、填充救缺失、异常才剔除、格式修一修——每条数据都值得先抢救一下
- **数据来自作者自己的竞赛**（《数据创意，尽显乡美》）：这批数据的毛病与竞赛中处理的真实数据一致，不是教科书编造的
- 与实践案例页的 `clean_data.py` 是同一套逻辑，实验是它的可视化版，两页互相印证

### Lab 03 · 数据量级感受器

**交互流程**

1. 滑块 + 数字框双向联动（1–999），配 GB / TB / PB / EB / ZB 五档单位下拉
2. 四个锚点按钮一键带入典型场景：一部 1080p 电影（2GB）→ 一块移动硬盘（1TB）→ 一个中型数据中心（约 1PB）→ 2025 年全球数据量（IDC 预测 175ZB）
3. 四张换算卡实时更新：能装多少部电影（2GB/部）、多少张手机照片（5MB/张）、多少本《红楼梦》全文（纯文本约 2.5MB/本）、100M 宽带理论满速要下载多久

**核心实现**：十进制口径 `UNIT_POW = {GB:9, TB:12, PB:15, EB:18, ZB:21}`（10ⁿ 字节）；`fmtCount` 按万 / 亿 / 万亿 / 亿亿做中文格式化，`fmtDuration` 从秒逐级换算到年。

**教学点**

- **把 5V 里的 Volume 变成体感**：「海量」「PB 级」说多了会麻木，换算成电影和下载年数才重新有感觉
- **量级直接推导架构动机**：滑到 PB 档，页面注释解释单块硬盘已装不下——这正是存储要「分布」到成百上千台机器（HDFS）、计算要「搬」到数据旁边（MapReduce/Spark）的原因；滑到 ≥175ZB 则弹出 IDC 预测的对照注解
- 换算口径明确标注为十进制、文件大小取常见估计值——重在感受量级，不假装精确

### 设计取舍

- **三个实验对应三条知识主线**：Lab 01 对应「技术栈」页的 MapReduce，Lab 02 对应「数据流程」页的清洗环节，Lab 03 对应「认知基础」页的 5V 特征——每个知识页面都有一条「看完概念就能上手」的通路，而不是三个孤立的小游戏。
- **原生 JS，不引入图表库**：站点承诺零依赖、可离线运行；三个实验需要的可视化（键值对切片、迷你条形图、中文数字格式化）手写各只要几十行，引入 D3 / Chart.js 反而会让实验逻辑淹没在库的用法里。代价是图表表现力有限——但实验的重点是过程，不是图表美观。
- **跑的是思想，不是工程**：浏览器里模拟的 MapReduce 没有真正的分布式节点，清洗台没有 pandas，换算器用的是估计值。每个实验都在页面上明说真实工程的做法（jieba 分词、Hadoop 集群、十进制口径），避免「大数据就这么简单」的错觉——实验是入口，不是终点。

## 本地运行

方式一：直接用浏览器打开 `index.html`。

```bash

python -m http.server 8090
# 访问 http://127.0.0.1:8090/bigdata-platform/index.html
```
