关于平台与作者

这是我的毕业设计，也是三年专业课的一份系统整理——它为什么被做出来、知识从哪来、我是谁，都在这一页。

Why

为什么有这个站

大二准备省赛的时候，我发现自己「知道 MapReduce 这个词，却说不清它和 Hive 到底谁管计算、谁管查询」——名词都听过，串不起来。大三把这个站定成毕业设计，最初的动机其实很朴素：把三年课上记的、实训跑的、比赛里踩过的坑，整理成一份以后自己还翻得动的东西。

真正动手整理才发现，「能讲给别人听」和「自己以为懂了」之间差得远。5V 特征画成图才理清了五个 V 各自对应哪层技术；清洗规则做成可以开关的实验，才体会到每条规则「救回多少数据」完全取决于业务口径。

所以这个站守着三条原则：概念配图（读图比读字快）、流程配代码（跑过才算懂）、板块配实验（动手实验室的三个小实验就是这么来的）。发现讲错的地方，欢迎来挑刺——挑刺也是学习。

技术实现：平台为纯静态多页面站点，使用 HTML5 + CSS3 + 原生 JavaScript 手写实现，图表由内置的轻量级渲染脚本绘制，无任何外部框架与 CDN 依赖，离线亦可运行——这本身也是一次前端与数据可视化的实践。

工程规范与交付

对标成熟知识类站点的交付标准
语义化与可访问性全站使用语义化标签与 aria 标注，示意图均含文字说明，键盘可达
响应式布局桌面 / 平板 / 移动三档断点，小屏下示意图横向可滚动，保证可读性
零依赖交付纯静态站点，无框架、无 CDN、无构建步骤，双击 index.html 即可离线运行
统一设计系统一套 CSS 变量与组件库贯穿 7 个页面，无页面级样式孤岛
SEO 基础每页独立 title 与 description，全站 favicon，链接语义明确
工程文档随项目附 README：功能特性、技术栈、目录结构与运行方式一应俱全
