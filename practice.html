Case 01 · Python

数据采集与清洗：把「脏数据」变干净

对应课程《数据采集与清洗》。下面的脚本完成两件事：从公开接口采集数据，并对数据做去重、补缺、类型统一与异常值剔除。

clean_data.py
# 1. 采集：读取原始数据文件（Python 标准库）
import csv

with open("villages_raw.csv", encoding="utf-8") as f:
    rows = list(csv.DictReader(f))
print("采集到", len(rows), "条记录")

# 2. 清洗：类型统一 —— 先收集合法收入，算出中位数备用
valid = []
for r in rows:
    try:
        valid.append(float(r["income"]))
    except ValueError:
        r["income"] = None
median = sorted(valid)[len(valid) // 2]

# 3. 清洗：去重 · 补缺 · 剔除异常
seen, clean = set(), []
for r in rows:
    if r["village_id"] in seen:                       # 去重
        continue
    seen.add(r["village_id"])
    income = median if r["income"] is None else float(r["income"])   # 补缺
    if income >= 0:                                 # 剔除异常值
        clean.append((r["village_id"], income))

# 4. 输出清洗结果
with open("villages_clean.csv", "w", encoding="utf-8-sig", newline="") as f:
    w = csv.writer(f)
    w.writerow(["village_id", "income"])
    w.writerows(clean)
print("清洗完成，剩余", len(clean), "条记录")

这段代码做了什么

数据清洗四步
去重按 village_id 保留唯一记录 对应「唯一性」
补缺用中位数填充缺失的收入值 对应「完整性」
纠错统一字段类型，非法值标记为空 对应「一致性」
剔除过滤掉收入为负的异常记录 对应「准确性」
实践心得：采集接口数据时，一定要先 观察数据分布再决定清洗策略，避免把真实的高值误判为异常值。
Case 02 · SQL

数据分析：用 SQL 从数据中找答案

对应课程《数据分析技术与应用》《数据库原理与 SQL 语言》。对清洗后的乡村电商数据做分组统计，找出销售额最高的省份。

sales_rank.sql
-- 按省份统计乡村电商销售额与订单量
SELECT
    province,
    COUNT(*)                AS order_cnt,
    ROUND(SUM(amount), 2)   AS total_sales,
    ROUND(AVG(amount), 2)   AS avg_amount
FROM dw_sales
WHERE dt BETWEEN '2024-01-01' AND '2024-12-31'
GROUP BY province
ORDER BY total_sales DESC
LIMIT 6;

Case 03 · Hadoop

分布式计算：MapReduce 词频统计

对应课程《Hadoop 大数据生态技术与应用》。词频统计是大数据界的「Hello World」，用 Map 拆分、Reduce 归约，理解分而治之的思想。

WordCount.java
// Mapper：把每一行文本拆成 <单词, 1>
public class WordMapper extends Mapper<LongWritable, Text, Text, IntWritable> {
    private final static IntWritable ONE = new IntWritable(1);
    private Text word = new Text();

    @Override
    protected void map(LongWritable key, Text value, Context ctx)
            throws IOException, InterruptedException {
        StringTokenizer itr = new StringTokenizer(value.toString());
        while (itr.hasMoreTokens()) {
            word.set(itr.nextToken());
            ctx.write(word, ONE);
        }
    }
}

// Reducer：把相同单词的计数累加
public class WordReducer extends Reducer<Text, IntWritable, Text, IntWritable> {
    @Override
    protected void reduce(Text key, Iterable<IntWritable> values, Context ctx)
            throws IOException, InterruptedException {
        int sum = 0;
        for (IntWritable v : values) sum += v.get();
        ctx.write(key, new IntWritable(sum));
    }
}
图 1　MapReduce 词频统计流程：分片 → 映射 → 归并 → 归约，最终把相同单词的计数汇总输出

并行局部计算

Shuffle 阶段

把相同单词的键值对汇聚到同一个 Reducer，是 MapReduce 中最耗性能的一环。

网络传输排序
